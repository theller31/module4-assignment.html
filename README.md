# Module 4 HTML Assignment

This project is a Knowledge Check assignment for Module 4. It demonstrates a solid understanding of core HTML concepts by implementing a complete, valid HTML5 page that includes forms, tables, navigation, and images.

## Project Overview

The HTML file includes the following major components:

## Part 1: Contact Form
- A form that allows users to input:
  - Name (text input)
  - Email (email input)
  - Message (textarea)
  - Submit button
- Bonus implemented: Radio buttons asking how the user found the site (Google, Social Media)

## Part 2: Product Table
- A table that displays:
  - Product Name
  - Price
  - Quantity
- Three example products are listed
- Bonus implemented: A header row labeling each column

## Part 3: Navigation Bar
- A simple navigation bar using an unordered list
- Includes links to:
  - Home
  - About
  - Contact

## Part 4: Images
- A placeholder image from https://placehold.co
- Bonus implemented: A second image styled with a rounded border using inline CSS

## File Contents
- `module4-assignment.html`: The main HTML page containing all required elements
- `README.md`: This readme file describing the project structure and implementation

## How to Use
1. Clone the repository or download the HTML file
2. Open `module4-assignment.html` in any modern web browser
3. Review the structure, form functionality, navigation, and styling

## Bonus Implementations
- All bonus tasks have been completed and are marked with HTML comments for easy reference
- Some basic inline and internal CSS is included to improve visual presentation

## Key Learning Outcomes
- Writing valid, semantic HTML5 code
- Structuring pages with forms, tables, images, and navigation
- Using input types and layout techniques
- Organizing code with proper indentation and comments
